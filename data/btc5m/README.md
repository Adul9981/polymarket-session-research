## 深水入场条件研究（2026-08-24）：什么时候低价买入值得做

回应“低价买入整体赚钱 ≠ 知道什么时候买”的缺口，用 2,740 个可用窗口
（414 万笔成交）做决策时点条件化研究。脚本
`study_deepwater_entry_conditions.py`，结果
`../btc5m-multiday/deepwater_entry_conditions_2026-08-24.json`。

```text
1. 分窗口（决定性）：两侧都触底 ≤20c 的 598 个窗口里，先触底侧胜率 84.8%；
   仅单侧触底的 2,105 个窗口里，先触底侧 0 胜。双侧占比 22.1%。
2. 分时段（无规律）：24 小时深水窗口分布均匀（每时 107–120 个），双侧占比
   15.6%–27.8%，双侧胜率 74%–96%，没有可用钟点规律。
3. 分时点（结构性陷阱）：第二侧触底中位在首触后 111s（p25=71s / p75=162s）；
   确认时首触侧价格中位 0.71，仅 5.9% 的窗口仍 ≤0.20 可成交。等确认再买
   首触侧，94% 的窗口已无法按 0.20 成交。
4. 反直觉负结果：等待“深水持续 W 秒”再入场是反向信号——胜率从 18.8%（W=0）
   降到 8.3%（W=90），全限价 EV 从 -1.24c 恶化到 -11.65c。赢家从深水快速
   反弹，滞留在深水的更可能是输家侧。
5. 结论：该买的条件（双向触底 + 先触底侧）真实但确认到得太晚，目前没有找到
   可执行的入场时点规则；下一步只有订单簿级成交仿真能验证是否存在更早的
   可执行代理信号。该研究已补入 08-24 讲解视频演示稿（SCENE 04B）。
```
