## 核心结论速览

### 1. Convert 机制（Yes + No = 1 的真正含义）

- 负风险组里，`NO(i)` 与「除 i 以外所有选项的 YES」在规则上完全等价，可免费互换。
- 一组 n 个选项、每档 X 份 NO 转换成现金 C 与补集 YES：`C = (n − 1) × X`。
- 利润不来自转换本身（转换是公平的），而来自市场定价偏离：
  `Σp（全套 YES 价格之和）> 1` 时买 NO 组合，`Σp < 1` 时买 YES 组合。
- 单轮毛利约 `X × (Σp − 1)`；实测吉达温度组 Σp = 1.0475~1.0640。

### 2. 目标交易者 e46m3

- 12 天内 5,000 次 CONVERSION、合计 $157,272、单笔中位 $0.70 → 24×7 自动化机器。
- 节奏：买 NO 组合 → Convert（现金 + 补集 YES）→ Merge 配对 → 再循环，单轮约 30 秒。
- 偏好：天气温度档 39%、选举/政治 16%、体育未来盘与足球比分盘。

### 4. 崩盘型深水买入验证（初步）

- ≤0.2 低价买入持有到期：投入 $91,368，净赚 +$57,923（+63%）；
- 但利润高度集中：14 个窗口盈利（+$112K），26 个窗口亏损（-$54K），
  前 3 个窗口贡献约 110% 总利润；
- 时序信号（样本 40 窗口）：两侧都触底时「先触底侧」胜率 79%（15/19）；
  仅单侧触底时胜率 0%（0/21）；
- 重要限制：仅一天样本、事后价格模拟，尚不能作为可执行策略，需多日回测。

- 5 分钟涨跌盘参考价（price to beat）需自行重建：5m/15m/4h 用 Chainlink 推送价，
  1h 用 Binance 小时开盘价，1d 用美东中午的分钟收盘价；
- 2026-08-07 起加密涨跌盘改为 Chainlink TWAP 结算（5m 用 30 秒 TWAP），
  旧的「盯最后一笔价」打法失效；
- 工具：runesleo/polymarket-toolkit（`pm updown`）、poly-strike-scraper、
  polymarket_price_to_beat、HF 数据集 krish301/polymarket-raw-5m。

### 6. 资金建议（讨论结论）

- 试水档 $50–100：当作试验费，明确可能归零；
- 认真档 $500–1000：能扛连续失败后才谈策略；
